# Technical reference

This section explains how MatSci-SAM represents vocabulary structure,
identifiers, and contribution history in its published metadata.
For instructions on adding terms, comparing definitions, voting, or commenting,
use [Quick Start](/docs) or the [user guide](/docs/guide).

Implementation details, service configuration, and development procedures are
documented separately in the repository under `docs/technical/`.

| [MatCore and the vocabulary](/docs/reference/matcore-and-the-vocabulary) | Dataset metadata elements and the Dublin Core crosswalk         |
| [Identifier policy](/docs/reference/identifier-policy)                   | Path grammar, allocation, and stability                         |
| [Curation and AI](/docs/reference/curation-and-ai)                       | Roles, semantic change, and model attribution                   |
| [Provenance model](/docs/reference/provenance-model)                     | Contribution histories, assertions, and privacy rules           |
