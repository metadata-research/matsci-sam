# Documentation

MatSci SAM is a collaborative dictionary for materials science
terminology, built by the Metadata Research Center at Drexel University.
Anyone can propose a definition, the community votes and comments, and an
AI assistant helps refine definitions when you want it to. Every entry is
also published as standards-based metadata for machines.

These guides cover what the site can do today.

- [Adding a term](/docs/adding-terms) covers the Add page and its two
  modes.
- [AI refinement](/docs/ai-refinement) covers the interactive loop for
  improving your definition with the model.
- [Votes, comments, and status](/docs/community) covers how definitions
  earn standing.
- [Provenance](/docs/provenance) covers the history view behind every
  term.
- [Search and Browse](/docs/search) covers finding terms.
- [Metadata Access](/docs/metadata-access) covers the SKOS and PROV-O
  serializations for data consumers.
