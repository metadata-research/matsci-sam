# Votes, comments, and status

Anyone can read votes and comments. You must sign in to cast a vote or
post a comment.

## Voting

Every definition has up and down controls. Selecting the same control
again removes your vote. Selecting the other control changes it. The
score is the number of upvotes minus the number of downvotes.

Definitions on a term page are ordered by score. The newest definition
appears first when scores are equal, and the leading definition receives
a stronger border when the term has multiple definitions.

## Definition status

Definitions earn standing through votes, shown as a small chip.

| Status | Meaning |
| --- | --- |
| proposed | A new definition, score below 2 |
| community-reviewed | Score of 2 or more |
| stable | Score of 5 or more |

Status is derived from votes at all times, so it rises and falls with
the score. The status also appears in the machine-readable record for
the term.

## Comments

Each definition has its own comment thread. A comment on a
human-authored definition is stored as discussion. A comment on an
AI-authored definition is also added to the term-level model context,
and the application requests an updated AI definition in the background.
The comment and resulting edit appear in the recorded
[provenance](/docs/provenance).

The [Discussion](/docs/discussion) page provides another way to comment
on definitions attached to recently added terms.
