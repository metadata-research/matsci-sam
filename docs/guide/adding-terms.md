# Adding a term

Sign in, complete your profile name, and open **Contribute** under
**Participate**. Check the destination vocabulary. **Working in** selects a
community vocabulary. **Everything** uses the default MatSci-SAM vocabulary.

## Confirm, write, review

1. Enter the term and select **Confirm term and find references**. The form
   checks for existing terms and retrieves possible ChEBI matches.
2. Write a definition that describes the meaning in your context. Include the
   broader class and distinguishing characteristics when useful. **Add an example**
   opens an optional example of use.
3. Select **Review definition**. Check the wording, attribution, **Citations**,
   example, and any **Files to publish**. **Back to writing** returns to the
   editor for changes.
4. Select **Publish new term**. The term and its first definition become public.
   An example you supply has its own attribution.

![A new term and definition in Simple view, with the review action below the form](/images/docs/help-add-simple.png)

The form links to the existing term when the label is already defined in the
destination vocabulary. Open that entry to compare or contribute definitions.
The same label in another vocabulary can identify a separate concept.

**Edit term** returns to confirmation. Confirming a changed term clears the
reference choices for the previous term. An applied model draft requires a
choice to keep the contribution or return to your earlier writing before
changing the term.

## Simple and Advanced views

Choose **Simple** or **Advanced** under **View**. Simple shows the writing form
with optional actions. Advanced adds ChEBI matches, matches across available
ontologies, and the selected hierarchy beside the form. These panels move
below the form on small screens.

The Advanced toolbar opens **Wolfram lookup**, **AI assistance**, **Add citation**,
and **Attach file** beneath the form. Simple has individual actions for
citations, files, and writing assistance. View changes preserve your draft,
selected sources, and tool settings. Ontology previews save no relationship.

## Writing with assistance

Select **Help me write** in Simple or **AI assistance** in Advanced to request
an optional model draft. Inspect the preview below the editor before using it.
[AI-assisted suggestions](/docs/ai-refinement) explains assistant choice,
request inputs, Undo, and attribution.

## Referencing a ChEBI definition

Open **Advanced** to inspect ChEBI matches. **Add to definition** inserts source
text and attaches a citation. **Copy** only copies text. The
[references guide](/docs/references#chebi-matches) explains these actions and
how to review citations before publication.

## Wolfram resources and model inputs

Use **Wolfram lookup** for reference information when available. Wolfram lookup
and the definition assistant are separate tools. A source enters an assistant
request only when you select it as context. See
[Wolfram lookup](/docs/references#wolfram-lookup).

## The contribution actions

| Action | Result |
| --- | --- |
| New term | A term and its first definition |
| Create a new version | The next revision of your own definition |
| Suggest an alternative | A separate definition drafted with a model from your critique |
| Propose a replacement | A definition you write to supersede another candidate |
| Comment | Discussion of the displayed revision |
| Add example | A separately attributed example of use |

[Reading and reviewing terms](/docs/community) explains existing-term actions.
Study contributions also record progress through the
[study activity](/docs/studies).

## Attach a file

Select **Attach a file** in Simple or **Attach file** in Advanced to upload
an example or source. Files stay private until
you select them for publication during review. See
[Files and examples](/docs/files-and-examples) for the steps and file limits.
